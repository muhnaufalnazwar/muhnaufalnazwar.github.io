# Muh. Naufal Nazwar — Portfolio

Personal portfolio website of **Muh. Naufal Nazwar**, Applied Accounting (D4) student at Universitas Negeri Makassar.

**Live site:** https://muhnaufalnazwar.github.io/

## Contents
- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `assets/naufal.webp`, `assets/naufal.png` — profile photo
- `assets/CV_Muh_Naufal_Nazwar.pdf` — downloadable CV

## Updating
Edit `index.html` (or replace files in `assets/`), commit, and push to `main`. GitHub Pages redeploys automatically within a minute or two.
